# 本机 CodeBuddy 与 OpenCode 2 会话管理

<!-- release-target: v1 -->

## 新增功能

- 支持使用独立本机配置集中管理 CodeBuddy 与 OpenCode 2 会话，按真实项目查看历史。
- 支持在原项目中继续 OpenCode 2 会话，保留原 CLI 的账户和权限设置。

## Bug 修复

- 修复 Windows 点击继续会话后终端未打开却提示成功的问题，恢复真实交互终端输入输出。

- 项目目录或原会话已失效时停止恢复并提示，避免在错误目录创建新会话。
- 停用默认来源后不再混入无关空项目；缺少项目路径的会话不会被猜测关联。
- 更新桌面运行时与兼容依赖补丁，修复已知生产依赖安全告警。
